# Pydantic AI

> Typed agent workflows with structured outputs and approvals.

Pydantic AI is the best fit when you want Python-native agent code that stays type-safe and produces structured output. It brings the Pydantic ergonomics into agent development.

## How it works

- Define agents with typed instructions and models.
- Add tools, dynamic instructions, and capabilities.
- Use structured outputs, human approval gates, durable execution, and graph support.
- Integrate MCP and observability through the Pydantic ecosystem.

## Where it fits in Harmonic Coding

- Use it when the output must be schema-safe.
- Use it for generated JSON/YAML plans, validations, or any workflow where type hints matter.
- Use it alongside spec-driven development when you want the agent to stay inside a contract.

## Why it matters

- It reduces "almost structured" outputs.
- It is a strong choice for workflow steps that need validation.

## Setup shape

```bash
pip install -U pydantic-ai
```
