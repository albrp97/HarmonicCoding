# CrewAI

> Role-based multi-agent automation with Crews and Flows.

CrewAI is a lean Python framework for collaborative agents. It is built around role-playing agents, task dependencies, and event-driven Flows for production work.

## How it works

- A Crew groups agents with roles, goals, and tasks.
- A Flow adds event-driven orchestration and more explicit control.
- The project ships skills for coding agents, so prompts can auto-activate guidance for setup, design, task writing, and docs lookup.

## Where it fits in Harmonic Coding

- Good for structured task pipelines where roles matter.
- Good for agent handoffs that are more workflow-like than chat-like.
- A strong adjacent option when you want a multi-agent stack but do not need LangGraph's lower-level graph control.

## Why it matters

- It is a practical bridge between "single agent" and "full workflow system."
- Its coding-agent skills show how to make agent workflows more discoverable.
