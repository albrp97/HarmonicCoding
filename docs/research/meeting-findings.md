# AI Coding Workshop Findings

Source: `docs/source/dsh-offsite-office-day.vtt`

## What the meeting is about

This is a workshop on development for the AI era. The core message is that teams should start experimenting with LLMs, GitHub Copilot, and related tooling now, not later.

The session frames this as an evolution from classic software development toward AI-assisted engineering:
- Software 1.0: humans write code directly
- LLM-assisted workflows: models help with classification, generation, and transformation
- AI-assisted engineering / Software 3.0 style workflows: prompts and examples become a first-class way to produce software

## Main themes extracted from the transcript

- **Adoption is about learning, not hype**: the goal is to get teams hands-on and comfortable.
- **Speed of change is the motivation**: the transcript emphasizes that AI tooling is changing too fast to ignore.
- **Copilot should be used in multiple modes**:
  - editor assistance
  - chat/help in VS Code
  - command help
  - CLI-based flows
- **Prompting becomes an engineering skill**: the meeting repeatedly treats prompts as reusable artifacts.
- **Reusable assets matter**: examples, prompt templates, and patterns are treated as assets that should be reused.
- **Factory/reuse patterns**: the team discusses a factory-style approach to making code generation scalable and reusable.
- **Hands-on is central**: the workshop includes group practice, demos, and live walkthroughs.
