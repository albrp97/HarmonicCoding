# Harmonic Coding Skills Index

- `planning-bootstrap` — run the repository map through ticket-generation workflow stack in order
- `preimplementation-checklist` — verify the repo is ready for serious feature implementation
- `setup-delivery-workflow` — define the repo setup, branch, PR, CI/CD, and validation baseline
- `implement-ticket` — deliver one ticket through code, docs, tests, PR, and repair loop
- `planning-layer-review` — review a planning layer before proceeding downstream
- `groom-backlog` — keep the backlog ordered, executable, and up to date
- `phase-feedback` — compare planned versus actual phase outcome and carry lessons forward
- `change-control` — adjust the plan only when material evidence justifies it
- `review-pr` — review changed work against requirements, tests, docs, and architecture
- `review-security` — perform a focused security review of a change or workflow
- `review-hotspots` — assess high-risk files and review hotspots before merge
- `triage-pr-comments` — classify PR review comments into already-fixed versus still-open work
- `create-user-test-scripts` — derive human and agent test scripts from journeys, phases, epics, or tickets
- `run-user-test` — execute a user-testing workflow and capture evidence and findings
- `run-markdown-pipeline` — execute an ordered markdown task list using Harmonic Coding workflow rules
- `pilot-runtime` — pilot the current runtime on real work and capture hardening actions
